Sobre o Modelo de Regressão

Este projeto utiliza um modelo de Regressão de Floresta Aleatória (RandomForestRegressor) para prever o valor de imóveis. Uma Floresta Aleatória é um método de aprendizado de máquina que opera construindo uma infinidade de árvores de decisão durante o treinamento e emitindo a classe que é o modo das classes (classificação) ou a previsão média (regressão) das árvores individuais.

O modelo foi treinado no conjunto de dados de habitação da Califórnia, que inclui características como renda média, idade da casa e localização. A acurácia do modelo é medida pelo R², que neste caso é de 81%, indicando que o modelo consegue explicar 81% da variância nos preços dos imóveis.
